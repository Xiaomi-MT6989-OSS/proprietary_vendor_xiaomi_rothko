# rothko vendor build metadata

Source-only companion for the unofficial LineageOS 23.2 adaptation.
No proprietary payloads are present in this repository or its reachable history.
PUBLIC_PROVENANCE.json pins 3056 stock-derived payloads and transformations;
payload-modes.json records their source file modes. Reconstruct them from your
own OS3.0.307.0.WNNCNXM dump using rothko-lineage-integration/BUILD.md.
The stock vendor is Android 14 / API 34; the framework is Android 16.
